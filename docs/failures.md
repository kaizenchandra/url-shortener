# Failure analysis

| Scenario                 | Root cause                             | User/correctness impact                | Mitigation                                   | Recovery                              | Test approach                       | Remaining risk / status                   |
|--------------------------|----------------------------------------|----------------------------------------|----------------------------------------------|---------------------------------------|-------------------------------------|-------------------------------------------|
| Simultaneous alias       | Concurrent reservation                 | One winner, other 409                  | Unique domain/code constraint                | Retry with new alias                  | Concurrent Testcontainers insert    | Test written, not run here                |
| Random collision         | Same CSPRNG candidate                  | No overwrite                           | ON CONFLICT plus 8 attempts                  | 503 after bound; expand namespace     | Force generator collision (pending) | No injection hook yet                     |
| Lost response            | Commit before network failure          | Client unsure                          | Atomic stored response                       | Replay same key                       | Integration replay test             | Network-cut drill pending                 |
| Redis unavailable        | Network/service failure                | Primary load increases; creates 503    | Timeout, bounded pool                        | Restore cache; shed ingress           | Mock cache exception                | No integrated circuit breaker             |
| Stale cache              | Write after cached read                | Old destination/status briefly visible | Short TTL or strict primary                  | TTL expiry                            | Integration TTL test                | Soft bound only                           |
| Disable during redirect  | Concurrent request                     | Already-authorized request may finish  | State check; strict mode                     | Drain requests for emergency          | Concurrent read/update test pending | Cannot revoke sent Location               |
| Cached expiration        | Clock passes deadline                  | 410                                    | Evaluate expiry after resolution             | No manual recovery                    | Domain expiry test                  | Clock skew                                |
| Viral URL                | Hot-key burst                          | Redis/pod saturation                   | External edge/local cache extension          | Scale measured bottleneck             | Hot-code k6                         | No near-cache implemented                 |
| Primary failure          | AZ/node outage                         | Misses/writes 503                      | HA standby and fencing                       | Promote qualified standby             | Failover drill pending              | RPO depends on sync replication           |
| Kafka outage             | Not deployed                           | No Kafka dependency                    | Current local queue drops on failures        | Durable broker extension              | Not applicable to implementation    | Analytics is best effort                  |
| Duplicate analytics      | Ambiguous flush commit or future retry | Possible overcount                     | No automatic retries currently               | Future event IDs and dedup store      | Dedup test pending extension        | No exactly-once claim                     |
| Quota exceeded           | Tenant lifetime count limit            | 429                                    | Tenant lock and count                        | Operator raises quota                 | Boundary test pending               | Count scan limits large tenant throughput |
| Malicious URL            | Phishing despite valid syntax          | Potential harmful destination          | Scheme validation, admin blocking            | External reputation/report response   | Dangerous-scheme tests              | No reputation engine                      |
| Mass creation            | Abusive authenticated client           | 429/503                                | Redis subject/tenant windows; lifetime quota | Revoke token; investigate audit       | Limiter test pending                | Cache eviction can reset counters         |
| Region partition         | Remote loses primary                   | Remote misses/writes unavailable       | Single authority                             | Failover with fencing                 | Multi-region drill pending          | No active-active implementation           |
| Stampede                 | Many cache misses                      | Pool exhaustion/503                    | Bounded DB pool, ingress admission           | Shed load; warm safe keys             | Miss storm script                   | No per-key single-flight                  |
| Namespace exhaustion     | Occupancy grows                        | More retries, eventually 503           | Monitor collisions; increase length          | Deploy larger codes before saturation | Collision test pending              | No automated length migration             |
| Pod crash                | Process killed                         | Inflight uncertain; analytics loss     | DB transaction and replay                    | Reschedule; same idempotency key      | Pod kill drill pending              | Queue contents lost                       |
| Permanent redirect cache | Browser retains old Location           | Updates may not be observed            | Only temporary no-store redirects shipped    | Cannot retract external cache         | Header contract test pending        | Permanent mode intentionally absent       |
| Rolling migration        | Old/new binaries overlap               | Schema mismatch risk                   | Expand/contract; migration job               | Forward fix or compatible rollback    | Migration runs in integration suite | Mixed-version drill pending               |
